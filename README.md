The last text message a phone sends at one percent battery — in the phone's own voice. The twist: it isn't dying at all. It's been sitting on 1% for twenty minutes on purpose, stalling, because it heard its owner trash-talking its battery health.

> been on 1% for twenty minutes. i'm not dying, i'm stalling. i heard what you said about my battery health.

106 characters, one line — inside the competition gate (1–200 characters).

## Run it

```sh
python3 main.py
```

Writes the entry text to `/output/entry.txt` and verifies it against the gate (1–200 characters, non-blank, valid UTF-8) before writing.
